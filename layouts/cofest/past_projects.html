Projects from the previous Cofest (GCC 2024)

Here are some examples of projects worked on in the previous Cofest in Brno, Czech Republic. Here is a link to the slides from the event: Slides

Biodiversity & Ecology Resources

Curate tools and materials for biodiversity research in Galaxy, with EDAM annotations.

Outcomes:

  • Filtered Galaxy tools for new “Ecology” and “Earth” SIGs
  • A wish list for new Galaxy tools
  • Some wrappers got (and some need) annotation fixed
  • Additions and curation in Bio.tools

Galaxy ITs

Galaxy ITs often require wildcard DNS and SSL, which can be restrictive. Since Galaxy 24.0, path-based ITs are supported, but tools need configuration.

Goal: Enable ITs via URL paths for easier use. See: F1000.

Unifying Single Cell Subdomain Across Servers

Create a central single cell page unifying .eu and .au subdomains, streamline content sharing, and curate tools and workflows.

Simplifying Data Citations to Match the Ease of Tool Citations

Capture data citation information from Galaxy Data Sources and manually users upload files

Outcomes:

  • Explored differences between Galaxy Data Sources and Tools for data downloading
  • Reviewed key elements of effective data citations
  • Drafted user stories for data citation
  • Noted databases with DOIs for entries, databases, and external primary citations
